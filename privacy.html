Privacy policy

Last updated: 28 September 2026.

YouTube tools is used only by the owner of the connected YouTube channel, on their own computer.

What it accesses

With the owner's consent through Google OAuth, it uses YouTube API Services to read and manage that channel: videos, thumbnails, captions, playlists, comments and analytics.

Where data goes

The OAuth token and any data returned by the API stay on the owner's computer. Nothing is sold, shared with third parties, or sent to any server operated by this tool — there is none.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
